# 基于动态思维链的文生视频方法研究系统

把一首中国古典诗词转换为一段连贯的视频。系统先用语言模型把诗词拆解为可分镜生成
的场景单元，再逐镜生成图像与视频片段，最后拼接成片；每一镜生成后都做跨媒体一致性
验证，未通过的镜头按失败原因修正后重生成。

## 方法：动态思维链

「动态」体现在两处：

1. **分镜数量不固定**，由每句诗词的意象密度决定，而不是简单地一句一镜。
   意象少于 2 个的相邻句合并为一镜（单独成镜会得到信息量极低的画面），
   超过 4 个的句子拆成两镜（一次生成难以同时呈现全部元素）。
2. **每一镜携带前一镜的画面状态**。后续镜头的提示词建立在前一镜已确定的画面之上，
   并在验证不通过时依据失败原因自动修正后重生成，形成带反馈的链条。

处理流程：

```
诗词输入 → 意象抽取 → 分镜规划 → 链式上下文 → 提示词装配
        → 逐镜生成 → 一致性验证 → 拼接成片
                ↑__________反馈修正__________|
```

## 模块结构

模块按方法步骤划分，与处理阶段一一对应。

| 模块 | 职责 |
|---|---|
| `t2video/settings.py` | 全局参数、风格词表、物理约束、验证阈值 |
| `t2video/account.py` | 本地账户与访问口令（PBKDF2-HMAC-SHA256） |
| `t2video/chain.py` | 意象抽取、分镜规划、链式上下文构建 |
| `t2video/prompt_builder.py` | 图像与视频提示词的按优先级装配 |
| `t2video/visual_api.py` | 视觉生成服务调用（V4 签名、限流、文生图、图生视频） |
| `t2video/assemble.py` | 素材下载、成片拼接、临时文件清理 |
| `t2video/verify.py` | 跨媒体一致性验证与指标计算 |
| `t2video/gui.py` | 图形界面与生成流程调度 |

## 跨媒体一致性验证

只报告能够计算出来的量。软件自身不含视觉语义模型，因此不做任何伪装成
物体检测的轮廓计数；需要语义对齐的项目保留打分器接口，未接入时明确标记为跳过。

| 指标 | 计算方法 | 判定作用 |
|---|---|---|
| 细节强度 | 边缘能量最强的一批分块的平均值 | 画面是否接近纯色或整体失焦 |
| 首帧相似度 | 输入图与视频首帧的 SSIM | 生成画面是否偏离输入图 |
| 亮度均值差 | 输入图与视频首帧的灰度均值差 | 曝光与色调是否突变 |
| 运动幅度 | 相邻帧的 Farneback 光流均值 | 画面是否几乎静止 |
| 帧间跳变 | 相邻帧的平均绝对差 | 是否出现闪烁或跳帧 |
| 片段衔接 | 前段末帧与后段首帧的 SSIM | 镜头切换处是否跳变 |

阈值按合成素材实测标定，定义在 `settings.VERIFY_THRESHOLDS`，可整体替换。

两处刻意的取舍：

- **细节强度不用全局拉普拉斯方差**。水墨与写意风格本就大量留白，整幅方差天然很低，
  用全局方差会把正常作品误判为模糊。改为统计边缘能量最强的一批分块后，
  只要画面中存在真实细节即可通过，而接近纯色的画面所有分块都接近零，仍会被拦下。
- **亮度连续性不用直方图相关系数**。实测同一张图与其压缩后视频首帧的 SSIM 达 0.998，
  直方图相关系数却是 -0.0015——画面色调集中在少数灰阶时直方图接近常数向量，
  相关系数被极小的数值扰动主导。改用数值稳定的亮度均值差。

## 安装

```bash
pip install -r requirements.txt
```

## 配置

复制 `.env.example` 为 `.env` 并填写密钥：

```env
ACCESS_KEY=你的火山引擎访问密钥
SECRET_KEY=你的火山引擎私钥
DEEPSEEK_API_KEY=你的 DeepSeek 密钥
```

火山引擎的两项密钥支持两种命名，程序会依次查找：
`ACCESS_KEY` / `SECRET_KEY`，或 `VOLC_ACCESS_KEY` / `VOLC_SECRET_KEY`
（同时存在时以不带前缀的优先）。

## 运行

```bash
python T2Video.py
```

首次运行会要求设置访问口令（至少 6 位）。口令用随机盐 + PBKDF2-HMAC-SHA256
迭代 20 万次派生后保存，磁盘上不存明文；校验用常量时间比对。
若忘记口令，删除 `config/account.json` 后重新启动即可重新设置。

操作步骤：设置/输入口令 → 选择艺术风格 → 输入诗词 → 点击「解析诗词」→
核对分镜并按需修改提示词 → 点击「生成视频」→ 在「生成资源」页签下载结果。

## 输出

以诗词内容为项目目录名，其下分别存放：

```
<诗词内容>/
├── 分镜图像/第N镜.jpg
├── 视频片段/第N镜.mp4
└── <诗词内容>.mp4       拼接后的成片
```

## 测试

```bash
python -m pytest tests -q
```

测试覆盖意象抽取与分镜规划、提示词装配、一致性验证、口令校验四个功能环节，
以及下载与拼接。网络请求全部用伪造会话，不会打真实接口。
